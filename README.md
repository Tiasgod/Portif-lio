# Tiago Dias — Portfólio

Site estático (HTML/CSS/JS puro) inspirado no visual do [Mapa de Carreira](https://tiasgod.github.io/mapa-de-carreira/).

## Editar conteúdo

Todo o conteúdo está direto em `index.html` — nome, projetos, tecnologias, formação e links de contato.
Ainda faltam: o link do CV em PDF para download e o repositório do projeto "Automação de Vagas" (estão como placeholders `#`).

## Rodar localmente

Basta abrir `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
npx serve .
```

## Deploy na Vercel

Importe o repositório na Vercel como projeto estático — nenhuma configuração de build é necessária (é HTML puro).
