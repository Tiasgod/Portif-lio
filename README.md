# Tiago Dias — Portfólio

Portfólio pessoal em HTML, CSS e JavaScript puro, com posicionamento voltado para **Análise de Dados, Engenharia de IA e Back-End**.

## Posicionamento

A comunicação principal do site segue esta ordem:

1. Analista de Dados
2. Engenheiro de IA
3. Back-End

O conteúdo foi organizado para mostrar não apenas tecnologias, mas também **projetos, atuação e foco atual de estudos**.

## Estrutura

- `index.html` — conteúdo e estrutura do portfólio
- `assets/css/style.css` — identidade visual, layout e responsividade
- `assets/js/main.js` — navegação ativa, animações e efeito do hero
- `assets/images/` — imagens utilizadas no site

## Projetos exibidos

- **Wattiz** — Product Owner / Back-End
- **Mercadez** — Desenvolvedor Back-End
- **Automação de Vagas** — Desenvolvedor Líder
- **Agente de IA Financeiro — IBM** — projeto em desenvolvimento

## Rodar localmente

Basta abrir `index.html` no navegador ou servir a pasta com qualquer servidor estático:

```bash
npx serve .
```

## Deploy na Vercel

Importe o repositório na Vercel como projeto estático. Nenhuma configuração de build é necessária.
